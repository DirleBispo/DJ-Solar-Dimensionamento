# DJ Solar Dimensionamento

Plataforma web para dimensionamento preliminar de sistemas fotovoltaicos da **DJ Solar Engenharia**.

## Objetivo

Centralizar o fluxo inicial de projeto solar: dados do cliente, consumo, estimativa de potência fotovoltaica, quantidade de módulos, inversor, área ocupada e geração estimada.

## Primeira etapa

A versão inicial terá:

- formulário de dimensionamento;
- cálculo preliminar por consumo mensal;
- sugestão de potência do sistema;
- estimativa de quantidade de módulos;
- estimativa de área necessária;
- comparação entre geração desejada e potência instalada;
- base preparada para proposta comercial, diagrama unifilar e lista de materiais.

## Stack

- Next.js (App Router)
- TypeScript
- CSS nativo
- Deploy planejado na Vercel
